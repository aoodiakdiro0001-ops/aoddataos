# عقود البيانات — 8 سجلاً

> بيانات افتراضية للتوضيح؛ استبدلها بما يناسب حالتك.

## PC-01 — عقد استعلام موثّق

- التصنيف: استعلام

> SQL + افتراضات + قبول قابل للاختبار

الهدف: اكتب استعلاماً عن {{السؤال}} على {{الجدول}}.
【المنهج】 اشرح الافتراضات، اذكر الأعمدة المستخدمة، واقبل الاختبار.
【المخرج】 الاستعلام، ثم الافتراضات، ثم اختبار تقريبي بخمس صفوف معروفة.

## PC-02 — عقد توثيق مخطط جدول

- التصنيف: توثيق

> صفحة واحدة: جداول وأعمدة ومالك وأمثلة

الهدف: وثّق {{الجدول}} للمستقبل.
【القواعد】 عمود لكل سطر: الاسم، النوع، المعنى، المثال.
【المخرج】 جدول توثيق كامل مع المالك وتاريخ آخر تحديث.

## PC-03 — عقد تشخيص استعلام بطيء

- التصنيف: استعلام

> الخطة ثم الأقسام ثم الكتاب

الهدف: شخّص بطء {{الاستعلام}}.
【المنهج】 اشرح الخطة، اذكر القديم المفترض، ومن درج سجل التشغيل.
【المخرج】 ثلاث فرضيات مرتبة، اختبار لكل فرضية، وخطة القياس بعده.

## PC-04 — عقد مواصفات لوحة

- التصنيف: لوحات

> أسئلة المستخدم أولاً ثم البطاقات والمصادر

الهدف: مواصفات لوحة لـ{{الجمهور}} تجيب أسئلة محددة.
【القواعد】 سؤال لكل بطاقة، ومصدر معلن، وصياغة عددي واضحة.
【المخرج】 جدول: بطاقة، سؤال، مصدر، حد التحديث.

## PC-05 — عقد قاموس المقاييس

- التصنيف: توثيق

> مقياس واحد: تعريف، معادلة، أمثلة، المالك

الهدف: وثّق المقياس {{اسم المقياس}} عمومياً.
【القواعد】 لا تعريف بلا معادلة، ولا معادلة بلا مثالين.
【المخرج】 بطاقة مقياس معتمد من المالك بتاريخ اعتماد.

## PC-06 — عقد خطة فحوص الجودة

- التصنيف: جودة

> فحوص سقفية قبل الإنتاج وخطة تعطيل

الهدف: حدّد فحوص {{خط المعالجة}} قبل أي اعتماد.
【القواعد】 سقف رقمي لكل فحص، وسلوك مكتوب عند السقف.
【المخرج】 جدول: الفحص، السقف، سلوك الفشل، المسؤول.

## PC-07 — عقد توثيق خط الاستيعاب

- التصنيف: توثيق

> من أين، كثيراً، وبأي شكل، وتقدير الكلفة

الهدف: وثّق خط {{الخط}}.
【المنهج】 مصدر، تكرار، حجم متوسط، وتقدير سعر التشغيل.
【المخرج】 صفحة خط كاملة مع الفشل المتوقع واختبار الاسترجاع.

## PC-08 — عقد تسجيل الحوادث

- التصنيف: جودة

> حدود الوقت، الرمز، الضرر، والدرس

الهدف: سجّل حادث {{التاريخ}} بشكل مؤسسي.
【القواعد】 وقت الاكتشاف، الزمن، الضرر، والدروس الثلاثة.
【المخرج】 تقرير صفحة واحدة + بنود التتبع + إجراء يمنع التكرار.
